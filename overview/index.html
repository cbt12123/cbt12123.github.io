从 Python 基础到大模型应用与算子开发

面向没有 Python 基础、数学知识需要重新补齐的读者。先理解具体例子，再学习抽象概念，最后进入机器学习、大模型与两条应用分支。

机器学习部分对局部公式先给定义、符号和数值例子，再展开推导；需要多个模块组合的公式则逐步建立。每章配参考实验与验收要求，帮助读者把知识转化为实际产出。

目前已完成六个部分的初稿。最后一部分将自写融合算子接入真实模型与HTTP服务，保留正确性、调用证据和实际性能结果。

阅读与运行

首次准备环境先看环境准备与复现：按学习部分选择 conda 环境，GPU 路线提供 WSL、Docker、模型挂载与 CUDA 开发镜像构建步骤，并用统一入口检查当前环境。

不确定从哪里开始时，先看学习路线与前置自测。后续源码中的陌生写法可查工程 Python 补读，公式中的符号与局部运算可查数学速查。补充的章节练习与产出验收覆盖35章，先独立解题再核对答案；后续实验按具体证据验收。

这些附录按需阅读，不增加进入第一章的门槛。大模型之后的 Agent 与算子是两条独立分支。

环境统一使用 conda + VS Code。第一部分使用 conda 的 base 环境，不设章末作品；通过短例子、随堂检查与参考答案确认理解。Python 语法示例只使用标准库，数组与绘图示例使用 NumPy、Matplotlib。

第二部分继续使用base；第三部分使用独立的handmade-ml环境，安装、版本组合与镜像站见第三部分运行指南。第五部分的Agent进程继续使用base，通过HTTP复用第四部分的模型与WSL镜像。第六部分继续使用conda和VS Code编辑，GPU实验复用WSL容器；环境及运行步骤见对应部分指南。

每个部分一个文件夹，章节为 Markdown 文件，图片集中保存在根目录 images/。在 VS Code 打开章节后，按 Ctrl+Shift+V 查看带图片的预览。

第三部分使用独立的handmade-ml环境（conda + VS Code），基础实验全部可在CPU离线运行。各章有参考脚本和验收要求；真实短信和预训练ResNet作为可选联网扩展。脚本位于script/part03/，报告和模型位于outputs/part03/，图片集中位于images/。详见第三部分运行指南。

第8～11章使用手写数字分类任务，依次介绍模型评价、手写神经网络、PyTorch训练和CNN。第12章介绍文本分类与字符序列，第13章介绍注意力与受控序列生成。各章区分真实数据、手算示例和辅助实验，并提供统一的命令行演示入口。

第11章提供完整NumPy CNN实现：从单窗口计算开始，完成卷积、池化、分类头、反向传播和参数更新，再训练真实手写数字模型。PyTorch版本用于进一步学习多层结构与图片预测。
