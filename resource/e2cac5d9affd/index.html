第一部分随堂练习与参考答案

每章两道短练习，不设置章末作品。先在纸上或终端写出自己的结果，再跳到答案核对；不需要提前完成后面章节。代码在 .py 文件中运行，命令在 VS Code 终端执行，使用 conda base。

第01章

练习A：追踪变量。 values=[2,4,6]，执行 alias=values、alias[0]=9，再计算 sum(values[1:])。写出列表和求和结果；若希望修改副本，应该怎样建立 alias？

练习B：返回一个结果。 写函数 passed_count(scores)，用循环返回大于等于60的成绩数量。检查 [0,59,60,100] 与空列表。函数内部不打印结果。

提示：切片不包含结束位置；计数变量先设为0。卡住时回看第1章的列表、循环、函数。

验收：先写预测结果，再运行确认；两组输入分别返回2和0；说明 return 与 print 的区别。

第03章

练习A：选对轴。 scores=np.array([[60,80],[90,100],[0,60]])。先预测形状、每科均值与每人均值，再分别运行 mean(axis=0)、mean(axis=1)。

练习B：避免广播误会。 比较 np.array([1,2,3]).shape 与 np.array([[1],[2],[3]]).shape。预测两者相加的形状；说明为什么不是把三对数字逐项相加。若只想逐项相加，怎样统一形状？

提示：从右侧对齐维度；长度相同或其中一方为1才能广播。

第01章参考答案

A：values 为 [9,4,6]，求和为10。普通赋值共享同一列表；本例用 alias=values.copy() 建立浅副本即可，列表元素都是数字。

B：

def passed_count(scores):
    count = 0
    for score in scores:
        if score >= 60:
            count += 1
    return count

assert passed_count([0, 59, 60, 100]) == 2
assert passed_count([]) == 0

常见错误：在循环内提前 return，只检查第一项；把 print(count) 当成返回值。

第02章参考答案

A：有效值为 [90.0,0.0]，无效3条。判断 score is not None，否则0也会被丢弃。缺失不直接补成真实0分。

B：该相对路径指向 项目/script/data/scores.csv。可将终端切回项目根目录后执行脚本；若脚本就在 script/ 下，也可用 Path(__file__).resolve().parent.parent / 'data' / 'scores.csv'。后一写法依赖实际目录结构，不是通用层级。

常见错误：认为相对路径总从 .py 文件所在目录出发。

第03章参考答案

A：形状 (3,2)；每科均值 [50,80]，每人均值 [70,95,30]。axis=0 汇总三个人，保留两科；axis=1 汇总两科，保留三个人。

B：形状分别 (3,) 与 (3,1)，相加得到 (3,3)，各行为 [2,3,4]、[3,4,5]、[4,5,6]。统一成 (3,) 可用 column.ravel()；统一成 (3,1) 可用 vector.reshape(-1,1)。

常见错误：代码能广播就认为数据含义正确；绘图前没有检查数组形状。
