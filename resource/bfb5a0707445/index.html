每章先完成两道局部练习，再运行正文参考实验。答案用来核对方法，不要求背诵。提交自己的计算、报告和简短结论；只复制作者报告不能说明已经完成实验。命令从项目根目录执行，使用 conda base。

第04章

练习A：手算两步。 对 L(w)=(w-3)²，从 w=0 出发，学习率为0.1。写出导数、两次参数更新和对应损失。

练习B：构造反例。 对 L(w)=-w²，w=0 的导数是多少？这能否证明该点是最小值？

提示：更新前在当前参数处计算导数；不要把“梯度为0”直接换成“最好”。

产出与验收：运行 python script/part02/04_calculus.py，保存 04-calculus.json 和 04-learning-rates.png；导数检查误差小于正文的 1e-6，手算与学习率0.1的两步结果一致。对0.05、0.4、1.1的实验分别说明现象与本例适用范围。

第05章

练习A：余弦与零向量。 计算 [1,2] 与 [2,1] 的点积、各自长度和余弦相似度。若其中一个向量为零向量，应该返回正常相似度还是明确处理无定义情形？

练习B：投影能否恢复。 矩阵 [[1,0],[0,0]] 作用在列向量 [3,4] 与 [3,9] 上，分别得到什么？从输出能唯一恢复输入吗？

提示：余弦的分母是两个长度相乘；相同输出可能对应多个输入。

产出与验收：运行 python script/part02/05_linear_algebra.py，保存 05-linear-algebra.json 和 05-transforms.png；记录查询与相似度排名，核对秩2近似误差不高于秩1。结论明确区分人为特征与学得的语义向量。

练习A：条件概率。 公平骰子中，A表示点数大于3，B表示点数为偶数。分别计算 P(A)、P(B)、P(A∩B)、P(A|B)；A与B独立吗？

练习B：预测概率与损失。 正确类别的概率分别为0.8、0.2，使用自然对数计算单个样本的负对数损失。若概率为0，为何不能得到有限损失？

提示：条件概率分母对应已知事件；独立需要联合概率等于边缘概率乘积。

第04章参考答案

导数为 2(w-3)。第一次：梯度-6，w=0.6，损失5.76；第二次：梯度-4.8，w=1.08，损失3.6864。-w² 在0的导数为0，但0是最大值。这些反例否定了“导数为零一定最优”的说法。

常见错误：更新后仍沿用旧梯度；把本例学习率范围推广到所有损失函数。

第05章参考答案

点积4，两向量长度均为 sqrt(5)，余弦为0.8。零向量使分母为0，需明确拒绝或约定处理，不能说它的余弦正常等于0。两次投影都得到 [3,0]，第二维信息丢失，不能唯一恢复。

常见错误：将点积当成余弦；将不可逆投影当作可逆旋转。

第06章参考答案

P(A)=1/2、P(B)=1/2、P(A∩B)=1/3、P(A|B)=2/3。联合概率不等于1/4，因此不独立。损失约0.2231与1.6094；-log(0)没有有限值。实际程序采用数值稳定计算，不把零概率损失写成0。

常见错误：颠倒 P(A|B) 的已知条件；混淆互斥与独立。

第07章参考答案

最少边为 A→B→D，2条边、成本10；最低成本为 A→C→E→D，3条边、成本4。阶梯计数依次为1、1、2、3、5。0阶的1代表不再走的唯一空方案，是递推组合的边界。

常见错误：把边数最少当作任意带权图的成本最小；忘记检查边界状态。
